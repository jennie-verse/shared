shared

Static modules that the personal web apps load directly over GitHub Pages. There is no app to open here.

Modules in v1/

  • sync.js — GitHub Contents API read/write plus an outbox retry queue (ES module)
  • sync-global.js — the same API for classic <script> tags
  • backup.js — JSON backup and restore helpers
  • fontsize.js — the six-step text size control
  • theme.css — shared pastel theme tokens

Versioning rule

Files under v1/ are never edited once published. A change means a new v2/ folder, with apps moved over one at a time. Editing v1/ in place would break every app that already depends on it.

See the repository for the full notes.
